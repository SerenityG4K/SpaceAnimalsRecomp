SpaceAnimalsRecomp — third-party software notices
==================================================

(Français : ce fichier liste les logiciels tiers fournis avec le paquet, leurs licences et où trouver leur code
source. Les textes complets des licences sont dans le dossier LICENCES, à côté de ce fichier.)

SpaceAnimalsRecomp itself is licensed under the GNU General Public License v3.0 (LICENSE in the source repository,
https://github.com/SerenityG4K/SpaceAnimalsRecomp). No file of the game is included in any package.

The full package (SpaceAnimalsRecomp-<version>-windows.zip) also contains, in the "outils" folder, the unmodified
binaries of the build tools below, so that the game can be built on a PC where nothing is installed, and SDL3, which
the game and the launcher use to read PlayStation, Switch Pro and Joy-Con controllers. GCC and glslang are reduced
to the files the build uses; the files kept are the original ones, unchanged. The update package (-update.zip)
contains none of these binaries (the launcher downloads a missing one from the address given below).

Since version 1.1.0 the "outils" folder also contains two upscaling libraries that the game can load at run time:
AMD FSR (section 5, MIT license) and NVIDIA DLSS (section 6). NVIDIA DLSS is proprietary software: it is NOT covered
by the GNU GPL, it comes under NVIDIA's own license, and the paragraph on corresponding source below does not apply
to it. The game runs without either of them.

Corresponding source: every component of sections 1 to 4 is distributed as unmodified upstream binaries. Its source
code is available, for the exact version shipped, at the addresses given below (GNU GPL v3 section 6(d), LGPL
section 4).
If one of these addresses stops working, open an issue on https://github.com/SerenityG4K/SpaceAnimalsRecomp/issues :
the corresponding source will be provided.
