SpaceAnimalsRecomp itself is licensed under the GNU General Public License v3.0 (LICENSE in the source repository,
https://github.com/SerenityG4K/SpaceAnimalsRecomp). No file of the game is included in any package.

The full package (SpaceAnimalsRecomp-<version>-windows.zip) also contains, in the "outils" folder, the unmodified
binaries of the build tools below, so that the game can be built on a PC where nothing is installed. GCC and glslang
are reduced to the files the build uses; the files kept are the original ones, unchanged. The update package
(-update.zip) contains none of these binaries.

Corresponding source: every component below is distributed as unmodified upstream binaries. Its source code is
available, for the exact version shipped, at the addresses given below (GNU GPL v3 section 6(d), LGPL section 4).
If one of these addresses stops working, open an issue on https://github.com/SerenityG4K/SpaceAnimalsRecomp/issues :
the corresponding source will be provided.
